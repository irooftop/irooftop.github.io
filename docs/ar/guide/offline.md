# الوضع دون اتصال والخصوصية

يحتفظ iRoof.top بمحادثاتك على جهاز الكمبيوتر الخاص بك. مع نموذج يعمل هو الآخر على جهاز الكمبيوتر الخاص بك، **لا يحتاج أي شيء إلى مغادرته**.
يجعل **الوضع دون اتصال** ذلك قاعدة يفرضها التطبيق، لا مجرد عادة.

## ما الذي يحدث محليًا

| الخطوة | مكان التشغيل | الشبكة |
|---|---|---|
| الاستيراد والتحليل وملف الأسلوب | جهاز الكمبيوتر الخاص بك | لا شيء |
| التخزين | ملفات JSON والوسائط في مجلد البيانات | لا شيء |
| البحث في السجل، ورموز PIN للروابط، مكتبة الوسائط | جهاز الكمبيوتر الخاص بك | لا شيء |
| وصف الصور والملصقات وGIF والفيديو | **نموذج الوسائط**، فقط عندما تضغط **الوصف بالذكاء الاصطناعي** | طلب واحد لكل عنصر إلى نقطة نهاية النموذج |
| تفريغ الصوت إلى نص | نموذج الوسائط، عندما تضغط **الوصف بالذكاء الاصطناعي** على رسالة صوتية أو تسجّل واحدة | طلب واحد إلى نقطة نهاية النموذج |
| رد واحد | **نموذج المحادثة**، عندما ترسل رسالة (أو يرسلها زائر) | طلبات إلى نقطة نهاية النموذج |
| ضغط سجل طويل | نموذج المحادثة، كجزء من رد، عندما يتجاوز السجل الميزانية | طلب إضافي واحد إلى نقطة نهاية النموذج |

لا يستدعي الاستيراد أي نموذج أبدًا. يحدث أول استدعاء عندما ترسل رسالة، أو تضغط **وصف**، أو تسجّل رسالة صوتية. يرسل الرد إلى النموذج سجلك المُصدَّر (حتى [ميزانية السجل](../reference/configuration#settings-only))، وملف الأسلوب، وأوصاف الوسائط. لذلك **المكان الذي يعمل فيه النموذج يحدد وجهة محادثتك**: تستقبلها نقطة نهاية سحابية، أما نموذج على جهازك فلا يستقبلها.

## التشغيل دون اتصال بالكامل

1. ثبّت [Ollama](https://ollama.com) أو [LM Studio](https://lmstudio.ai)، أو شغّل `llama-server` من llama.cpp.
2. حمّل **نموذج محادثة يدعم استدعاء الأدوات**، و**نموذج رؤية** إذا أردت وصف الصور والملصقات.
3. في **الإعدادات** اختر نقطة النهاية والنموذج، ثم فعّل **دون اتصال**:

| الخادم | عنوان URL الأساسي |
|---|---|
| Ollama | `http://localhost:11434/v1` |
| LM Studio | `http://localhost:1234/v1` |
| `llama-server` من llama.cpp | `http://localhost:8081/v1` (منفذه الافتراضي `8080` هو منفذ iRoof.top، لذا شغّله بـ `llama-server --port 8081`) |

4. اضغط **اختبار**. يرسل طلبًا صغيرًا ويعرض النموذج والمضيف اللذين ردّا. يمكنك إيقاف الشبكة ومتابعة المحادثة.

يُضبط **تطبيق سطح المكتب** في الإعدادات. لا يقرأ الصدفة أو ملف `.env` الخاص بك (انظر [تطبيق سطح المكتب](./desktop))، لكنه يحترم `ROOFTOP_OFFLINE` و`OPENAI_*` إذا كانت في البيئة التي شُغّل بها. يقرأ الخادم البيئة (و`.env`):

::: code-group

```sh [Homebrew / خادم cargo]
# --offline يعادل ROOFTOP_OFFLINE=1
OPENAI_BASE_URL=http://localhost:11434/v1 OPENAI_MODEL=llama3.1 rooftop --offline
```

```sh [Docker]
docker run -p 8080:8080 -v rooftop-data:/data \
  --add-host=host.docker.internal:host-gateway \
  -e ROOFTOP_OFFLINE=1 \
  -e OPENAI_BASE_URL=http://host.docker.internal:11434/v1 -e OPENAI_MODEL=llama3.1 \
  ghcr.io/irooftop/rooftop
```

:::

في Docker، يشير `localhost` إلى الحاوية نفسها، لذا استخدم `host.docker.internal` (يلزم الخيار `--add-host` على Linux فقط). إذا رفض Ollama الاتصال، فاجعله يستمع على كل الواجهات (`OLLAMA_HOST=0.0.0.0`).

### ما الذي يفرضه الوضع دون اتصال

| | الوضع دون اتصال |
|---|---|
| المحادثة، وتلخيص السجل، ووصف الوسائط، وتفريغ الصوت | يُرفض ما لم تكن نقطة النهاية [محلية](#local-means) |
| خوادم MCP عبر HTTP | تُرفض ما لم تكن محلية؛ يظهر الخطأ في الإعدادات |
| المشاركة عبر الإنترنت (`<الاسم>.iroof.top`) | مُطفأة: لا يبدأ عميل الترحيل، والمفتاح مقفل |
| بوت Telegram، الخاص أو المشترك | لا يبدأ |
| GIF عبر URL | لا يستطيع الذكاء الاصطناعي إرسال GIF من URL غير محلي |
| روابط Wi‑Fi | تعمل |

يفشل الطلب المرفوض قبل إنشاء أي اتصال، وتوضح الرسالة السبب: `الوضع دون اتصال: https://openrouter.ai
ليس نقطة نهاية محلية`. يُرفض أيضًا إعادة التوجيه من نقطة نهاية محلية إلى مضيف آخر. تظهر شارة **دون اتصال** صغيرة في رأس الشريط الجانبي طالما الوضع مفعّل. يُحفظ الإعداد. يفعّل `--offline` / `ROOFTOP_OFFLINE=1` الوضع بغض النظر عن الإعدادات، ولا تستطيع الإعدادات إيقافه.

#### معنى "محلي" {#local-means}

`localhost`، وعنوان الحلقة المرجعية (`127.0.0.0/8`، `::1`)، وعناوين الشبكات الخاصة (`10/8`، `172.16/12`، `192.168/16`، `fc00::/7`)، وعناوين link-local، والأسماء `*.local` و`*.internal` (مثل `host.docker.internal`). يُعدّ النموذج الموجود على جهاز آخر في شبكتك المنزلية محليًا، لأنه لا يغادر شبكتك أبدًا. تُقيَّم الأسماء من خلال كتابتها، ولا يُبحث عنها.

### ما الذي لا يستطيع الوضع دون اتصال التحقق منه

* **خوادم MCP من نوع stdio** برامج على جهاز الكمبيوتر الخاص بك. يشغّلها iRoof.top لكنه لا يرى بماذا تتصل، لذا أضف فقط ما تثق بأنه سيبقى محليًا.
* **تفريغ الصوت** يستخدم واجهة برمجة تطبيقات المحادثة (جزء `input_audio`)، لا واجهة Whisper `/audio/transcriptions`. يتطلب خادمًا ونموذجًا محليين يقبلان الصوت هناك. إذا لم يكن نموذجك يقبله، تُحفظ الرسالة الصوتية وتُرسل مع ذلك؛ الناقص فقط هو نصها.
* **توليد الصور والصوت** موجود فقط كـ[أدوات MCP](../features/mcp). في الوضع دون اتصال، استخدم خادم MCP محليًا لذلك.
* يفتح الأشخاص الذين تشاركهم روابط Wi‑Fi الخاصة بك في متصفحاتهم. يحكم الوضع دون اتصال هذا التطبيق، لا أجهزتهم.

## المشاركة مع الأصدقاء بأمان {#share-with-friends-safely}

| الرابط | ما الذي يحدث |
|---|---|
| **Wi‑Fi** `http://<عنوان IP الخاص بك>:8737/s/<الاسم>` | لا يغادر شبكتك المحلية أبدًا |
| **الإنترنت** `https://<الاسم>.iroof.top/s/<الاسم>` | يفتح التطبيق اتصال WebSocket واحدًا صادرًا إلى المحور، فيمرّر المحور عبره طلبات HTTP الخاصة بالزائر وردود تطبيقك |

مع رابط الإنترنت، يبقى تصديرك ومحادثاتك والنموذج على جهاز الكمبيوتر الخاص بك، ولا يخزن المحور أيًا منها.
لا يحفظ المحور إلا سجلًا للحساب: اسمك، وتجزئة سرّك، ووقت آخر مرة رآك فيها.

كن واضحًا بشأن ما *لا* يمنحه هذا. ينهي المحور TLS، لذلك مثل أي وكيل عكسي، يرى تقنيًا الحركة التي تمر عبره: ما يكتبه الزائر، وردود الشخصية، والسجل الذي يسمح الرابط للزوار بقراءته (**يستطيع الزوار قراءة التصدير**، والافتراضي **لا شيء**). يمرّر فقط صفحات الزوار (`/s/…`، `/api/s/…`، ملفات الصفحة) ويتخلص من ملفات تعريف الارتباط في الاتجاهين؛ ولا يمكن الوصول إلى واجهة المالك وإعداداتك عبره أبدًا. إذا كانت هذه الثقة كثيرة عليك، فاستخدم روابط Wi‑Fi، أو [شغّل محور الترحيل الخاص بك](../reference/relay-hub).
[المزيد عن روابط المشاركة](../features/share-links).

مع **الوضع دون اتصال**، يكون ترحيل iroof.top مُطفأً. تبقى روابط Wi‑Fi تعمل.

## بوت Telegram {#the-telegram-bot}

تنشر [الرد من Telegram](../features/telegram) في مجموعتك:

* **رسائل الزوار** الجديدة (الاسم، واسم الرابط، والنص، أو تسمية وسائط مع وصفها أو نصها المفرّغ، ومعاينة قصيرة للرسالة التي يردون عليها)، و**ردود** الذكاء الاصطناعي؛
* لا تنشر أبدًا السجل المُصدَّر. لا تُرسل الرسائل القديمة.

ليس للبوتات تشفير من طرف إلى طرف: يمرّ النص عبر Telegram بصيغة نصية عادية. مع **البوت المشترك**، يمرّ أيضًا عبر المحور، الذي يحفظ فقط أي مجموعة تنتمي إلى أي حساب. يتحدث **البوت الخاص بك** مباشرة مع Telegram، دون المحور. يُطفئ الوضع دون اتصال الاثنين.

## إلى أين تذهب بياناتك

| البيانات | إلى أين تذهب |
|---|---|
| التصديرات والمحادثات والإعدادات ومفتاح API | مجلد البيانات على جهاز الكمبيوتر الخاص بك |
| الاستيراد وملف الأسلوب | لا تذهب إلى أي مكان |
| السجل وملف الأسلوب ورسائلك | نقطة نهاية النموذج التي اخترتها، في كل رد |
| الصور والصوت | نقطة نهاية نموذج الوسائط، عند **الوصف** أو عندما تسجّل رسالة صوتية |
| رسائل الزوار عبر رابط Wi‑Fi | جهاز الكمبيوتر الخاص بك ونقطة نهاية نموذجك |
| رسائل الزوار عبر رابط الإنترنت | المحور (أثناء العبور)، وجهاز الكمبيوتر الخاص بك، ونقطة نهاية نموذجك |
| رسائل الزوار عبر Telegram | بالإضافة إلى Telegram، والمحور للبوت المشترك |
| الوضع دون اتصال | نقطة نهاية النموذج المحلي فقط، وروابط Wi‑Fi فقط، ولا Telegram |
