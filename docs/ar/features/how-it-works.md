# كيف يعمل

<div class="wide">

![كيف يعمل iRoof.top](/how-it-works.svg)

</div>

يتحول كل تصدير إلى الرسائل المُوحَّدة نفسها. ثم تُعاد كل أفعال الشخصية على النموذج كـ**استدعاء أداة**، ليتعلم النموذج *كيف* يتفاعل الشخص، لا ما يكتبه فحسب، ويرد بالطريقة نفسها.

## الأفعال كاستدعاءات أدوات

| ما فعلته الشخصية | استدعاء الأداة في السجل وفي الردود المباشرة |
|---|---|
| فقاعة نصية، وربما ردّ أو اقتباس جزئي | `send_message {text, reply_to?, quote?}` |
| ملصق | `send_sticker {sticker_id, reply_to?}` |
| GIF من المكتبة، أو URL من أداة MCP | `send_gif {gif_id \| url, caption?}` |
| صورة، فيديو، صوت، ملف صوتي، ملف | `send_media {media_id, caption?}` |
| منشور مُعاد توجيهه | `forward_message {message_id}` |
| تفاعل | `react {message_id, emoji}` |
| *(استرجاع سجل أقدم)* | `search_history {query}` |

تتحول عدة استدعاءات في الدور الواحد إلى عدة فقاعات. وتتحول رسائل الطرف الآخر إلى أسطر مختصرة تشير إليها المعرّفات:

```text
#52108 19:08 ↩ ردّ على #52107 (أنت: "لازانيا جدتي 🍝"): أنت لم تصنع اللازانيا ولو مرة واحدة.
<sticker stk_156dbb381a>: قطة ترتدي قبعة طهاة تحرّك قِدرًا
تفاعلت 😂 مع #52107 ("لازانيا جدتي 🍝")
```

## موجّه النظام

| الجزء | |
|---|---|
| من ينبغي أن يكون | تقدير معرفة الشخصية وأسلوبها، ومعرفة ما لا تعرفه الشخصية أبدًا |
| ملف الأسلوب | من *التصدير كاملًا*: طول الرسائل، وحالة الأحرف، وعلامات الترقيم، واستخدام الرموز التعبيرية والملصقات، وعادات الرد والتفاعل، وعدد الفقاعات في كل دور، وأمثلة حرفية |
| المكتبة | الملصقات وGIF والوسائط مع كيفية استخدامها |
| الملاحظات | ما كتبته عن الشخص |

يكون الموجّه **ثابتًا** للمحادثة: لا ساعة ولا عدّادات. يقرأ النموذج الوقت من فواصل `— اليوم —` وطوابع `HH:MM`، وكل طلب هو بادئة مطابقة بايتًا بايت للطلب الذي يليه، لذلك تستمر ذاكرات التخزين المؤقت للموجّهات لدى المزودين في الإصابة.

## المحادثات الطويلة {#long-chats}

```
 ميزانية السجل ────────────────────────────────────────────▶
 ┌──────────────────────┬────────────────────────────────────────┐
 │ الذاكرة (≤ 350 كلمة) │ الأدوار الأخيرة، مقطوعة عند 60 % من الميزانية │
 └──────────────────────┴────────────────────────────────────────┘
   العلاقة، والوقائع،     تبقى نقطة القطع ثابتة لفترة طويلة،
   والمواضيع، والنكات     فتبقى البادئة المخزّنة مؤقتًا كذلك
```

عندما يتجاوز السجل المُعاد تشغيله الميزانية، يطوي الرد التالي أولًا الأدوار الأقدم (والذاكرة السابقة) في ملخص قصير. لا يُستهلك شيء عند الاستيراد أو عند فتح محادثة. يبقى ملف الأسلوب مبنيًا على التصدير كاملًا، ويصل `search_history` إلى كل رسالة قديمة. يُعرض `usage` الخاص بالرموز (الموجّه، والمخزّن مؤقتًا، والإكمال) في `{ }`.

## مكتبة الوسائط

يقرأ نموذج المحادثة النص، لذلك فالملصق ليس سوى `<sticker stk_…>` حتى يُوصف. يرسل **الوصف بالذكاء الاصطناعي** صور العناصر الناقصة إلى نموذج الوسائط، ويجب أن يدعم الرؤية.

* تُرسل GIF وملصقات الفيديو والفيديو كـ**4 إطارات بالترتيب**، ليرى النموذج الحركة. يتطلب هذا [ffmpeg](https://ffmpeg.org) (`brew install ffmpeg`، `apt install ffmpeg`، `winget install ffmpeg`)، وإلا فتُستخدم الصورة المصغّرة.
* **إعادة** تصف عنصرًا واحدًا من جديد. يمكن تحرير أي وصف يدويًا.
* تنتمي الأوصاف إلى التصدير، وتخدم كل محادثاته.

جرّب بنفسك باستخدام [واجهة سطر الأوامر](../reference/cli): `rooftop convert <التصدير> --persona "Jonas Weber"`.
