# 署名されていないアプリを開く

デスクトップのインストーラーはまだ署名や公証がされていないため、初回起動時に macOS と Windows で警告が表示されます。
これは一度だけの手順です。アプリを一度許可すれば、同じ方法でインストールされたアップデートの後も、通常どおり開きます。

::: tip 避けたいですか？
[アプリを自分でビルド](./desktop#build-it-yourself)するか、[サーバー](./getting-started#install)を実行してブラウザで使ってください。`brew install irooftop/tap/rooftop`、`cargo install rooftop`、[Docker](./docker)があります。
:::

## macOS

![macOS で未確認のアプリを開く：「開けません」の警告、完了、システム設定、プライバシーとセキュリティ、このまま開く、パスワード、そしてアプリが開く](/how-to-open-an-unsigned-app-on-macos.svg)

macOS 15 Sequoia 以降では：

1. **iRoof.top** を開きます。macOS は「"iRoof.top"を開けません：Apple は検証できませんでした…」と表示します。**完了**をクリックします。
2. **アップルメニュー → システム設定… → プライバシーとセキュリティ**を開きます。
3. **セキュリティ**まで下にスクロールします：「"iRoof.top"は、Mac を保護するためブロックされました」。**このまま開く**をクリックします。
4. **このまま開く**で確定し、パスワードを入力するか Touch ID を使います。

**このまま開く**ボタンは、アプリを開こうとしてから約 1 時間だけ表示されます。見当たらない場合は、アプリをもう一度開いて、プライバシーとセキュリティに戻ってください。

macOS 14 Sonoma 以前では、Finder でアプリを右クリック（または Control キーを押しながらクリック）して**開く**を選び、もう一度**開く**を押します。

### ターミナルから

ブラウザがダウンロードに付けた検疫フラグを外すことでも開けます。

```sh
xattr -r -d com.apple.quarantine /Applications/iRoof.top.app
```

いつも成功するわけではありません。新しい macOS では、`/Applications` 内のアプリを変更するには、ターミナルにプライバシーとセキュリティの**App 管理**（または**フルディスクアクセス**）が必要な場合があり、それがないと `Operation not permitted` で失敗します。上記の手順は常に成功します。

::: details「"iRoof.top"は壊れているため開けません」
このメッセージも、壊れたダウンロードではなく検疫フラグを意味します。**キャンセル**をクリック（**ゴミ箱に入れる**ではありません）して、上の `xattr` コマンドを実行するか、システム設定の手順に従ってください。
:::

## Windows

SmartScreen がインストーラーに対して**Windows によって PC が保護されました**と表示します：

1. **詳細情報**をクリックします。
2. **実行**をクリックします。

ブラウザがダウンロードを保留する場合（*一般的にダウンロードされるファイルではありません*）は、ダウンロード一覧を開いて**⋯ → 保存**を選び、次に**さらに表示 → 必要に応じて保存**を選びます。`.msi` では、右クリック → **プロパティ** → **許可する**にチェック → **OK** の順でも、実行前に解除できます。

**スマート アプリ コントロール**がオンの Windows 11 では、署名されていないアプリは**実行**ボタンなしでブロックされます。代わりに[サーバー](./getting-started#install)を使うか、**Windows セキュリティ → アプリとブラウザー コントロール → スマート アプリ コントロールの設定**でスマート アプリ コントロールをオフにしてください。

## Linux

Linux は署名されていないアプリをブロックしませんが、AppImage には実行の許可が必要です。

```sh
chmod +x iRoof.top_amd64.AppImage    # または：プロパティ → アクセス権 → ファイルをプログラムとして実行を許可
./iRoof.top_amd64.AppImage
```

FUSE に関する警告が出た場合（`dlopen(): error loading libfuse.so.2`）は、`libfuse2` をインストールするか（Ubuntu 24.04：`sudo apt install libfuse2t64`）、`--appimage-extract-and-run` を付けて実行してください。

パッケージは、ローカルの署名されていないパッケージを受け付けるパッケージマネージャーでインストールします。

```sh
sudo apt install ./iRoof.top_amd64.deb     # Debian、Ubuntu
sudo dnf install ./iRoof.top.x86_64.rpm    # Fedora
```
