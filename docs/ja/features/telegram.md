# Telegram から返信

共有リンクは、訪問者のメッセージを Telegram のグループに投稿できます。そこで自分で返信するか、カウントダウンが終わると AI が返信します。訪問者はどちらの場合も同じ「入力中…」を見るので、誰が返信したかは分かりません。「人間か AI か？」というゲームや、AI が明白な質問を処理するサポート窓口のような使い方ができます。

```
 訪問者 ──▶ 共有リンク ──▶ 🤖 ボット ──▶ あなたの Telegram グループ
                                        ├─ ✍️ 返信         あなたが返信
                                        └─ 🤖 AI の返信（10 秒） AI がすぐに、またはカウントダウン後に返信
```

## 設定

**設定 → Telegram** には、ボット、接続されているかどうか、ボットが参加しているすべてのグループが表示されます。

| モード | 設定 | メッセージの送信先 |
|---|---|---|
| **共有ボット** | 不要 | リレー（iroof.top）経由。ほかのボットと同じく平文 |
| **自分のボット** | [@BotFather](https://t.me/BotFather) で作成し、トークンを貼り付けて**接続** | あなたのアプリと Telegram の間で直接 |
| `TELEGRAM_BOT_TOKEN` | サーバー上。`TELEGRAM_CHAT_ID` でグループを制限 | 直接。設定より優先 |

そのあと**グループに追加**を押します。

1. **Telegram アプリ**、**Telegram Web** でリンクを開くか、スマートフォンで QR コードを読み取ります。どちらのリンクもコピーできます。
2. グループを選ぶ（または作成する）し、確定します。
3. ダイアログが緑になり、そのグループが設定とすべての共有リンクに表示されます。

共有ボットでは、リンクには 1 時間有効な使い捨てのコードが含まれ、そのグループをあなたのアプリだけに結び付けます。

最後に、共有リンクの**Telegram グループ**でそのグループを選び、AI が何秒後に返信するかを設定します（`0` = **AI の返信**を押したときだけ）。

::: tip プライバシー
グループに投稿されるのは、新しい訪問者のメッセージと AI の返信だけで、エクスポートした履歴は決して投稿されません。オフラインモードはボットをオフにします。詳細：[オフラインとプライバシー](../guide/offline#the-telegram-bot)。
:::

::: tip 公開アドレスは不要
どちらの種類のボットも long polling を使うので、ノートパソコンからでも動きます。ボットのトークンは一度に 1 つのアプリでしか動きません。
:::

## 返信する 3 つの方法

1. ボットの「✍️ … このメッセージに返信」というプロンプトに返信する。
2. **返信**を押さずに、いつでも訪問者のメッセージ（または AI の返信）に返信する。
3. **返信**を押して、そのまま入力する。15 分間、あなたのメッセージはその訪問者に送られ、各返信のあとにさらに 2 分間送られるので、1 つの返信が複数のメッセージにまたがれます。

3 つ目の方法では、ボットが通常のグループメッセージを見られる必要があります。プライバシーモードをオフにする（@BotFather → `/setprivacy` → Disable のあと、ボットを追加し直す）か、ボットを管理者にしてください。方法 1 と 2 は常に動きます。

::: warning 信頼できるグループを使う
グループの誰でも返信できます。テキストの返信だけが転送され、AI の返信はリンクの上限に数えられます。
:::
