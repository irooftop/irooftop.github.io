# शुरुआत करें

## इंस्टॉल करें {#install}

| | कमांड |
|---|---|
| **डेस्कटॉप ऐप**, macOS | `brew install --cask irooftop/tap/irooftop` |
| **डेस्कटॉप ऐप**, Windows | [इंस्टॉलर (.exe)](https://github.com/irooftop/rooftop/releases/latest/download/iRoof.top_x64-setup.exe) या [.msi](https://github.com/irooftop/rooftop/releases/latest/download/iRoof.top_x64_en-US.msi) |
| **डेस्कटॉप ऐप**, Linux | [AppImage](https://github.com/irooftop/rooftop/releases/latest/download/iRoof.top_amd64.AppImage), [.deb](https://github.com/irooftop/rooftop/releases/latest/download/iRoof.top_amd64.deb) या [.rpm](https://github.com/irooftop/rooftop/releases/latest/download/iRoof.top.x86_64.rpm) |
| **सर्वर**, macOS और Linux | `brew install irooftop/tap/rooftop` (फिर `brew services start rooftop`) |
| **सर्वर**, Rust ≥ 1.88 वाली कहीं भी | `cargo install rooftop` |
| **सर्वर**, कंटेनर | `docker pull ghcr.io/irooftop/rooftop` ([Docker](./docker)) |

डेस्कटॉप ऐप को टर्मिनल की ज़रूरत नहीं है: [डेस्कटॉप ऐप](./desktop) देखें।

## चलाएँ

```sh
export OPENAI_BASE_URL=https://openrouter.ai/api/v1   # डिफ़ॉल्ट; OpenAI-संगत कोई भी API चलेगा
export OPENAI_API_KEY=…
export OPENAI_MODEL=openai/gpt-6-luna                 # टूल कॉलिंग को सपोर्ट करना चाहिए
rooftop                                               # http://127.0.0.1:8080
```

वेरिएबल्स उस जगह की `.env` फ़ाइल में भी रह सकते हैं जहाँ से आप `rooftop` शुरू करते हैं, या बाद में **सेटिंग्स** में सेट किए जा सकते हैं।
सेटिंग्स में **टेस्ट** एक छोटा अनुरोध भेजता है और सरल शब्दों में बताता है कि क्या गड़बड़ है, जैसे
"openrouter.ai ने API कुंजी अस्वीकार की (401)"।

चाहते हैं कि कुछ भी आपके कंप्यूटर से बाहर न जाए? एक स्थानीय मॉडल और [ऑफ़लाइन मोड](./offline) का उपयोग करें।

## आपकी पहली चैट

```
 ┌──────────────┐     ┌────────────────────┐     ┌──────────────────────┐
 │ 1. चैट       │ ──▶ │ 2. पेज पर         │ ──▶ │ 3. नई चैट: चुनें कि │
 │ एक्सपोर्ट करें│     │    छोड़ें          │     │ AI किसका रोल निभाए  │
 └──────────────┘     └────────────────────┘     └──────────────────────┘
```

1. Telegram Desktop या WhatsApp से [एक चैट एक्सपोर्ट करें](./export)।
2. फ़ोल्डर, `.zip`, या WhatsApp का `.txt` पेज पर छोड़ें (या `rooftop --import <फ़ोल्डर>` से शुरू करें)।
3. **नई चैट** दबाएँ और पर्सोना चुनें: दूसरा व्यक्ति, या आप खुद ("अपनी शैली में खुद से बात करना")।

::: tip अपनी चैट के बिना आज़माएँ
रिपॉज़िटरी में [`examples/`](https://github.com/irooftop/rooftop/tree/main/examples) में दो काल्पनिक एक्सपोर्ट हैं:
Telegram पर जोनास और प्रिया लज़ानिया बनाते हैं, WhatsApp पर सोफ़िया और डैनियल एक वीकेंड बिताते हैं।

```sh
git clone https://github.com/irooftop/rooftop && cd rooftop
rooftop --import ./examples/telegram
```
:::

### एक्सपोर्ट नहीं है? नोट्स से शुरू करें

**नई चैट → नोट्स से** को केवल उनका नाम (आपका नाम वैकल्पिक है) और उनके बारे में कुछ पंक्तियाँ चाहिए: वे कौन हैं,
आप क्या साझा करते हैं, वे कैसे लिखते हैं ("मुझे जानू कहते हैं, इतालवी में छोटे संदेश, बहुत सारे ❤️")। AI केवल इन्हीं नोट्स से उनकी तरह लिखता है। इतिहास के बिना कोई स्टाइल प्रोफ़ाइल या मीडिया लाइब्रेरी नहीं होती, इसलिए नोट्स जितना बताएँगे कि वे कैसे लिखते हैं, परिणाम उतना ही करीब होगा। आप चैट में कभी भी नोट्स संपादित कर सकते हैं (✎) और चैट को किसी और की तरह लिंक से साझा कर सकते हैं। चैट हटाने से उसमें जो भी था, वह सब हट जाता है।

## विंडो में क्या है

| बटन | क्या करता है |
|---|---|
| **साझा करें** | [लिंक](../features/share-links) ताकि दोस्त पर्सोना से बात कर सकें |
| **मीडिया लाइब्रेरी** | हर स्टिकर, GIF, फ़ोटो और वॉइस संदेश, और AI उनके बारे में जो जानता है |
| **नोट्स** | वे बातें जो एक्सपोर्ट में नहीं हैं। पर्सोना उन्हें पढ़ता है, विज़िटर कभी नहीं |
| **`{ }`** | मॉडल को भेजा गया सटीक JSON और इस्तेमाल हुए टोकन |
| **फिर से लिखें** | पर्सोना का आख़िरी जवाब हटाकर उसे दोबारा लिखता है |
| **पहले वे लिखें** | पर्सोना बातचीत शुरू करता है |
