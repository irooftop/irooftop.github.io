# শুরু করুন

## ইনস্টল {#install}

| | কমান্ড |
|---|---|
| **ডেস্কটপ অ্যাপ**, macOS | `brew install --cask irooftop/tap/irooftop` |
| **ডেস্কটপ অ্যাপ**, Windows | [ইনস্টলার (.exe)](https://github.com/irooftop/rooftop/releases/latest/download/iRoof.top_x64-setup.exe) বা [.msi](https://github.com/irooftop/rooftop/releases/latest/download/iRoof.top_x64_en-US.msi) |
| **ডেস্কটপ অ্যাপ**, Linux | [AppImage](https://github.com/irooftop/rooftop/releases/latest/download/iRoof.top_amd64.AppImage), [.deb](https://github.com/irooftop/rooftop/releases/latest/download/iRoof.top_amd64.deb) বা [.rpm](https://github.com/irooftop/rooftop/releases/latest/download/iRoof.top.x86_64.rpm) |
| **সার্ভার**, macOS ও Linux | `brew install irooftop/tap/rooftop` (তারপর `brew services start rooftop`) |
| **সার্ভার**, Rust ≥ 1.88 থাকলে যেকোনো জায়গায় | `cargo install rooftop` |
| **সার্ভার**, কন্টেইনার | `docker pull ghcr.io/irooftop/rooftop` ([Docker](./docker)) |

ডেস্কটপ অ্যাপের জন্য টার্মিনাল লাগে না: [ডেস্কটপ অ্যাপ](./desktop) দেখুন।

## চালানো

```sh
export OPENAI_BASE_URL=https://openrouter.ai/api/v1   # ডিফল্ট; OpenAI-সামঞ্জস্যপূর্ণ যেকোনো API চলবে
export OPENAI_API_KEY=…
export OPENAI_MODEL=openai/gpt-6-luna                 # টুল কলিং সমর্থন করতে হবে
rooftop                                               # http://127.0.0.1:8080
```

ভেরিয়েবলগুলো যেখানে আপনি `rooftop` চালান সেখানকার `.env` ফাইলেও থাকতে পারে, অথবা পরে **সেটিংস**-এ সেট করা যায়।
সেটিংস-এর **পরীক্ষা** একটি ছোট অনুরোধ পাঠায় এবং সহজ ভাষায় জানায় কী ভুল হয়েছে, যেমন
"openrouter.ai API কী প্রত্যাখ্যান করেছে (401)"।

কিছুই আপনার কম্পিউটার থেকে বের না হোক এমন চান? একটি স্থানীয় মডেল এবং [অফলাইন মোড](./offline) ব্যবহার করুন।

## আপনার প্রথম চ্যাট

```
 ┌──────────────┐     ┌────────────────────┐     ┌──────────────────────┐
 │ 1. চ্যাট     │ ──▶ │ 2. পেজে            │ ──▶ │ 3. নতুন চ্যাট: বেছে  │
 │ এক্সপোর্ট    │     │    ড্রপ করুন       │     │ নিন AI কার ভূমিকা নেবে│
 └──────────────┘     └────────────────────┘     └──────────────────────┘
```

1. Telegram Desktop বা WhatsApp থেকে [একটি চ্যাট এক্সপোর্ট করুন](./export)।
2. ফোল্ডার, `.zip`, বা WhatsApp-এর `.txt` পেজে ড্রপ করুন (বা `rooftop --import <ফোল্ডার>` দিয়ে শুরু করুন)।
3. **নতুন চ্যাট** চাপুন এবং পার্সোনা বেছে নিন: অন্য ব্যক্তি, অথবা আপনি নিজে ("আপনার নিজের স্টাইলে নিজের সাথে কথা বলা")।

::: tip নিজের চ্যাট ছাড়াই চেষ্টা করুন
রিপোজিটরিতে [`examples/`](https://github.com/irooftop/rooftop/tree/main/examples)-এ দুটি কাল্পনিক এক্সপোর্ট আছে:
Telegram-এ জোনাস ও প্রিয়া ল্যাজানিয়া বানায়, WhatsApp-এ সোফিয়া ও ড্যানিয়েল একটি সপ্তাহান্ত কাটায়।

```sh
git clone https://github.com/irooftop/rooftop && cd rooftop
rooftop --import ./examples/telegram
```
:::

### এক্সপোর্ট নেই? নোট থেকে শুরু করুন

**নতুন চ্যাট → নোট থেকে** শুধু তাঁর নাম (আপনার নাম ঐচ্ছিক) এবং তাঁর সম্পর্কে কয়েক লাইন চায়: তিনি কে,
আপনারা কী ভাগ করেন, তিনি কীভাবে লেখেন ("আমাকে সোনা বলে ডাকেন, ইতালীয় ভাষায় ছোট বার্তা, অনেক ❤️")। AI শুধু এই নোটগুলোর উপর ভিত্তি করে তাঁর মতো করে লেখে। ইতিহাস ছাড়া কোনো স্টাইল প্রোফাইল বা মিডিয়া লাইব্রেরি থাকে না, তাই নোট যত বেশি তিনি কীভাবে লেখেন তা বলবে, ফল তত কাছাকাছি হবে। চ্যাটে যেকোনো সময় নোট সম্পাদনা করতে পারবেন (✎), এবং অন্য চ্যাটের মতো লিংক দিয়ে চ্যাট শেয়ার করতে পারবেন। চ্যাট মুছে ফেললে তার ভেতরের সবকিছু মুছে যায়।

## উইন্ডোতে কী আছে

| বোতাম | কী করে |
|---|---|
| **শেয়ার** | [লিংক](../features/share-links), যাতে বন্ধুরা পার্সোনার সাথে কথা বলতে পারে |
| **মিডিয়া লাইব্রেরি** | প্রতিটি স্টিকার, GIF, ছবি ও ভয়েস বার্তা, এবং AI তাদের সম্পর্কে যা জানে |
| **নোট** | এক্সপোর্টে যা নেই এমন ব্যক্তি সম্পর্কিত বিষয়। পার্সোনা পড়ে, ভিজিটররা কখনো পড়ে না |
| **`{ }`** | মডেলে পাঠানো সঠিক JSON এবং ব্যবহৃত টোকেন |
| **পুনরায় লিখুন** | পার্সোনার শেষ উত্তর বাদ দিয়ে আবার লেখে |
| **প্রথমে তাঁকে লিখতে দিন** | পার্সোনা কথোপকথন শুরু করে |
