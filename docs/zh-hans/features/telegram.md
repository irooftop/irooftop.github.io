# 从 Telegram 回复

分享链接可以把访客的消息发布到一个 Telegram 群组中。你可以在那里亲自回复，或者当倒计时结束时由 AI 回复。两种情况下访客都看到相同的“正在输入…”，无法分辨是谁回复的：这可以是一个“真人还是 AI？”的游戏，也可以是一个由 AI 处理常见问题的客服台。

```
 访客 ──▶ 分享链接 ──▶ 🤖 机器人 ──▶ 你的 Telegram 群组
                                  ├─ ✍️ 回复          你来回复
                                  └─ 🤖 AI 回复（10 秒） AI 立即回复，或在倒计时结束时回复
```

## 设置

**设置 → Telegram** 会显示机器人、是否已连接，以及它所在的每个群组。

| 模式 | 设置 | 消息发送到 |
|---|---|---|
| **共享机器人** | 无需设置 | 通过中继（iroof.top），与其他机器人一样以明文形式 |
| **自己的机器人** | 用 [@BotFather](https://t.me/BotFather) 创建，粘贴令牌，然后点击**连接** | 直接发送到你的应用与 Telegram 之间 |
| `TELEGRAM_BOT_TOKEN` | 在服务器上；`TELEGRAM_CHAT_ID` 限制群组 | 直接发送；优先于设置 |

然后点击**添加到群组**：

1. 在 **Telegram 应用**、**Telegram Web** 中打开链接，或用手机扫描二维码。两个链接都可以复制。
2. 选择一个群组（或创建一个）并确认。
3. 对话框会变成绿色，该群组会出现在设置中以及每个分享链接里。

使用共享机器人时，链接会携带一个一次性代码，有效期一小时，它只把群组绑定到你的应用。

最后，在分享链接的 **Telegram 群组**中选择该群组，并设置 AI 在多少秒后回复（`0` = 只有在你点击 **AI 回复**时）。

::: tip 隐私
只有新的访客消息和 AI 的回复会发布到群组，从不会发布导出的历史。离线模式会关闭该机器人。详情：[离线与隐私](../guide/offline#the-telegram-bot)。
:::

::: tip 不需要公网地址
两种机器人都使用长轮询，因此从笔记本电脑也能工作。一个机器人令牌一次只能在一个应用中使用。
:::

## 三种回复方式

1. 回复机器人的“✍️ … 回复此消息”提示。
2. 随时回复访客的消息（或 AI 的回复），无需点击**回复**。
3. 点击**回复**，然后直接输入。15 分钟内，你的消息会发给该访客；每次回复后还会再持续 2 分钟，因此一次回复可以跨越多条消息。

第三种方式要求机器人能看到普通的群组消息：关闭隐私模式（@BotFather → `/setprivacy` → Disable，然后重新添加机器人），或者把它设为管理员。方式 1 和 2 始终有效。

::: warning 使用你信任的群组
群组中的任何人都可以回复。只有文字回复会被转发，AI 回复会计入链接的限制。
:::
