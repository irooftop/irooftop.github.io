# Telegram سے جواب دیں

شیئر لنک اپنے وزیٹرز کے پیغامات ایک Telegram گروپ میں پوسٹ کر سکتا ہے۔ آپ وہاں خود جواب دیتے ہیں، یا جب کاؤنٹ ڈاؤن ختم ہو تو AI جواب دیتا ہے۔ وزیٹرز دونوں صورتوں میں ایک جیسا "typing…" دیکھتے ہیں اور نہیں بتا سکتے کہ جواب کس نے دیا: یہ "انسان یا AI؟" کا کھیل ہے، یا ایک سپورٹ ڈیسک جہاں AI آسان سوالات سنبھالتا ہے۔

```
 وزیٹر ──▶ شیئر لنک ──▶ 🤖 بوٹ ──▶ آپ کا Telegram گروپ
                                        ├─ ✍️ Reply         آپ جواب دیتے ہیں
                                        └─ 🤖 AI reply (10 s) AI ابھی جواب دیتا ہے، یا کاؤنٹ ڈاؤن ختم ہونے پر
```

## ترتیب

**Settings → Telegram** بوٹ، اس کا کنکشن، اور وہ ہر گروپ دکھاتا ہے جس میں وہ ہے۔

| موڈ | ترتیب | پیغامات کہاں جاتے ہیں |
|---|---|---|
| **Shared bot** | کچھ نہیں | ریلے (iroof.top) سے، کسی بھی بوٹ کی طرح سادہ متن میں |
| **Own bot** | [@BotFather](https://t.me/BotFather) سے ایک بنائیں، ٹوکن چسپاں کریں، **Connect** | براہ راست آپ کی ایپ اور Telegram کے درمیان |
| `TELEGRAM_BOT_TOKEN` | سرور پر؛ `TELEGRAM_CHAT_ID` گروپس کو محدود کرتا ہے | براہ راست؛ Settings پر فوقیت رکھتا ہے |

پھر **Add to a group** دبائیں:

1. لنک کو **Telegram ایپ** میں، **Telegram Web** میں کھولیں، یا QR کوڈ کو فون سے اسکین کریں۔ دونوں لنک کاپی کیے جا سکتے ہیں۔
2. کوئی گروپ چنیں (یا نیا بنائیں) اور تصدیق کریں۔
3. ڈائیلاگ سبز ہو جاتا ہے، اور گروپ Settings اور ہر شیئر لنک میں ظاہر ہوتا ہے۔

مشترکہ بوٹ کے ساتھ لنک ایک بار استعمال ہونے والا کوڈ رکھتا ہے، جو ایک گھنٹے تک درست ہے، اور گروپ کو صرف آپ کی ایپ سے جوڑتا ہے۔

آخر میں شیئر لنک میں **Telegram group** کے تحت گروپ چنیں، اور مقرر کریں کہ کتنے سیکنڈ بعد AI جواب دے (`0` = صرف جب آپ **AI reply** دبائیں)۔

::: tip رازداری
گروپ میں صرف نئے وزیٹر پیغامات اور AI کے جواب پوسٹ ہوتے ہیں، ایکسپورٹ شدہ تاریخ کبھی نہیں۔ آف لائن موڈ بوٹ کو بند کر دیتا ہے۔ تفصیل: [آف لائن اور رازداری](../guide/offline#the-telegram-bot)۔
:::

::: tip عوامی پتے کی ضرورت نہیں
دونوں قسم کے بوٹ long polling استعمال کرتے ہیں، اس لیے یہ لیپ ٹاپ سے بھی کام کرتا ہے۔ ایک بوٹ ٹوکن ایک وقت میں صرف ایک ایپ میں کام کرتا ہے۔
:::

## جواب دینے کے تین طریقے

1. بوٹ کے "✍️ … reply to this message" پرامپٹ کا جواب دیں۔
2. وزیٹر کے پیغام (یا AI کے جواب) کا کسی بھی وقت جواب دیں، **Reply** دبائے بغیر۔
3. **Reply** دبائیں، پھر بس لکھیں۔ 15 منٹ تک آپ کے پیغامات اس وزیٹر کو جاتے ہیں، اور ہر جواب کے بعد مزید 2 منٹ، تاکہ ایک جواب کئی پیغامات پر پھیل سکے۔

تیسرے طریقے کے لیے بوٹ کو عام گروپ پیغامات دیکھنے ہوتے ہیں: پرائیویسی موڈ بند کریں (@BotFather → `/setprivacy` → Disable، پھر بوٹ کو دوبارہ شامل کریں) یا اسے ایڈمن بنائیں۔ پہلے دو طریقے ہمیشہ کام کرتے ہیں۔

::: warning ایسا گروپ استعمال کریں جس پر آپ بھروسہ کرتے ہوں
گروپ میں کوئی بھی جواب دے سکتا ہے۔ صرف متنی جواب آگے بھیجے جاتے ہیں، اور AI کے جواب لنک کی حد میں شمار ہوتے ہیں۔
:::
