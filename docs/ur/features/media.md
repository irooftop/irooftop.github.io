# تصاویر اور آواز

کچھ لوگ زیادہ تر تصاویر بھیجتے ہیں، کچھ زیادہ تر صوتی پیغامات میں بات کرتے ہیں۔ iRoof.top دونوں عادتیں محفوظ رکھتا ہے۔

## انہیں سمجھنا

میڈیا لائبریری میں **Describe with AI** اسٹیکرز، GIFs اور تصاویر کی تفصیل بناتا ہے، اور **صوتی پیغامات کو متن میں بدلتا ہے** (transcribe)، *میڈیا ماڈل* کے ذریعے، جسے تصاویر اور آڈیو دونوں قبول کرنے ہوں۔ اسے Settings میں یا `OPENAI_MEDIA_MODEL` سے مقرر کریں، مثلاً OpenRouter پر `google/gemini-3.5-flash-lite`۔ تفصیلات صرف اس وقت بنتی ہیں جب آپ بٹن دبائیں، اور مقامی ماڈل اور [آف لائن موڈ](../guide/offline) کے ساتھ تصاویر کبھی آپ کے کمپیوٹر سے باہر نہیں جاتیں۔

```text
<voice message 0:05: «what was said»>
```

جب ایک قسم غالب ہو، تو انداز کا پروفائل یہ بتاتا ہے، مثلاً "talks mostly in voice messages (10 of 10)"۔

### بڑی لائبریریاں

ایک طویل چیٹ میں دسیوں ہزار اسٹیکرز، GIFs اور تصاویر ہو سکتی ہیں۔ میڈیا لائبریری ماڈل کے ٹوکن وہاں خرچ کرنے میں مدد کرتی ہے جہاں ان کی اہمیت ہو:

| کنٹرول | کیا کرتا ہے |
|---|---|
| قسم کے ٹیبز | All، Missing، Described، Stickers، GIFs، Photos، Videos، Voice، گنتی کے ساتھ |
| ترتیب | سب سے زیادہ استعمال (ڈیفالٹ)، سب سے کم، حال ہی میں استعمال، سب سے پہلے استعمال |
| استعمال کی گنتی | وہ آئٹمز چھپائیں جو 2، 3، 5، 10 یا 25 بار سے کم استعمال ہوئے |
| تلاش | تفصیلات اور آئی ڈیز میں |

**Describe N with AI** وہی آئٹمز بیان کرتا ہے جو دکھائی دے رہے ہیں اور جن کی تفصیل نہیں بنی، **منتخب ترتیب میں اوپر سے نیچے**، چار ایک ساتھ۔ ہر تفصیل آتے ہی محفوظ ہو جاتی ہے۔ پیش رفت کی سطر دکھاتی ہے کہ کتنے مکمل ہوئے، کتنی ناکامیاں ہیں، رفتار اور باقی وقت۔ اسی بٹن کی جگہ **Stop** آ جاتا ہے: کسی بھی وقت روکیں، اور اگلی بار باقی سے جاری رہتا ہے۔ بڑی چیٹ کے لیے اچھی شروعات: *Most used first* اور *Used 3+ times*۔

## آپ کے صوتی پیغامات

خالی کمپوزر میں بھیجنے کا بٹن Telegram کی طرح **مائیکروفون** بن جاتا ہے۔ ریکارڈنگ براؤزر میں WAV میں بدلتی ہے، اپ لوڈ ہوتی ہے اور متن میں بدلی جاتی ہے۔ شیئر لنکس کے وزیٹرز بھی ریکارڈ کر سکتے ہیں۔

::: info
براؤزر ریکارڈنگ صرف `https://` یا `localhost` پر اجازت دیتے ہیں۔
:::

## کردار کی تصاویر اور صوتی پیغامات

ایک MCP سرور جو تصاویر بنائے اور ایک جو بولے، جوڑیں:

```json
{
  "img": {"command": "npx", "args": ["-y", "@dtst/img"],
          "env": {"OPENAI_BASE_URL": "https://openrouter.ai/api/v1", "OPENAI_API_KEY": "${OPENAI_API_KEY}", "OPENAI_MODEL": "meta/muse-image"}},
  "tts": {"command": "npx", "args": ["-y", "@dtst/tts"],
          "env": {"OPENAI_BASE_URL": "https://openrouter.ai/api/v1", "OPENAI_API_KEY": "${OPENAI_API_KEY}",
                  "OPENAI_MODEL": "google/gemini-3.8-flash-lite-tts", "OPENAI_VOICE": "Laomedeia"}}
}
```

پھر کردار کو دو مزید عمل ملتے ہیں:

| عمل | کیا کرتا ہے |
|---|---|
| `send_voice {text}` | تقریر کے ٹول کو کال کرتا ہے (WAV، ناکامی پر mp3) اور صوتی پیغام بھیجتا ہے |
| `send_photo {prompt, caption?}` | تصویر کے ٹول کو کال کرتا ہے اور تصویر بھیجتا ہے |

* تقریر کا ٹول جڑا ہو تو کردار کے اپنے، متن میں بدلے گئے صوتی پیغامات `send_voice` کے طور پر دوبارہ دکھائے جاتے ہیں، تاکہ ماڈل وہ عادت اس شکل میں دیکھے جسے وہ جاری رکھ سکے۔
* *Chat details* میں **Voice** (مثلاً `Puck`) کردار کو اپنی آواز دیتا ہے۔
* MCP ٹول جو بھی دوسری تصویر یا آڈیو لوٹائے وہ چیٹ میڈیا `gen_…` بن جاتا ہے (مواد سے جانچی جاتی ہے، 25 MB تک، اور چیٹ کے ساتھ حذف ہوتی ہے)۔

::: tip اخراجات
ہر تصویر یا صوتی پیغام ایک اضافی ادا شدہ کال ہے: `meta/muse-image` کے ساتھ تقریباً $0.01 فی تصویر، اور TTS کے چند سیکنڈ۔
:::
