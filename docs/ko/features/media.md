# 사진과 음성

주로 사진을 보내는 사람도 있고, 주로 음성 메시지로 말하는 사람도 있습니다. iRoof.top은 두 습관 모두를 유지합니다.

## 이해하기

미디어 라이브러리의 **AI로 설명**은 스티커, GIF, 사진을 설명하고, **음성 메시지를 텍스트로 변환**합니다. 이때 이미지와 오디오를 받아들여야 하는 *미디어 모델*을 씁니다. 설정에서 또는 `OPENAI_MEDIA_MODEL`로 지정하세요. 예를 들어 OpenRouter의 `google/gemini-3.5-flash-lite`입니다. 설명은 버튼을 누를 때만 만들어지며, 로컬 모델과 [오프라인 모드](../guide/offline)를 쓰면 사진은 절대 사용자의 컴퓨터를 떠나지 않습니다.

```text
<음성 메시지 0:05: «말한 내용»>
```

한 종류가 대부분을 차지하면, 말투 프로필이 그것을 알려 줍니다. 예: "주로 음성 메시지로 말함 (10개 중 10개)".

### 큰 라이브러리

긴 채팅에는 수만 개의 스티커, GIF, 사진이 있을 수 있습니다. 미디어 라이브러리는 모델의 토큰을 가장 중요한 곳에 쓰도록 도와줍니다.

| 컨트롤 | 기능 |
|---|---|
| 종류 탭 | 전체, 누락, 설명됨, 스티커, GIF, 사진, 동영상, 음성(개수 표시) |
| 정렬 | 가장 많이 사용(기본), 가장 적게 사용, 최근 사용, 처음 사용 |
| 사용 횟수 | 2, 3, 5, 10, 25회 미만으로 사용된 항목을 숨깁니다 |
| 검색 | 설명과 ID에서 |

**N개 AI로 설명**은 보이는 것 중 아직 설명되지 않은 것을, **선택한 순서대로 위에서 아래로**, 네 개씩 정확히 설명합니다. 각 설명은 도착하는 즉시 저장됩니다. 진행 줄에는 완료된 수, 실패, 속도, 남은 시간이 표시됩니다. 같은 버튼이 **중지**로 바뀌며, 언제든 멈출 수 있고, 다음 실행은 남은 항목부터 이어 갑니다. 큰 채팅의 좋은 시작은 *가장 많이 쓴 것부터*와 *3회 이상 사용*입니다.

## 사용자의 음성 메시지

입력창이 비어 있으면 보내기 버튼이 Telegram처럼 **마이크**가 됩니다. 녹음은 브라우저에서 WAV로 변환되고, 업로드되어 텍스트로 변환됩니다. 공유 링크의 방문자도 녹음할 수 있습니다.

::: info
브라우저는 `https://` 또는 `localhost`에서만 녹음을 허용합니다.
:::

## 페르소나의 사진과 음성

이미지를 만드는 MCP 서버와 말하는 MCP 서버를 연결하세요.

```json
{
  "img": {"command": "npx", "args": ["-y", "@dtst/img"],
          "env": {"OPENAI_BASE_URL": "https://openrouter.ai/api/v1", "OPENAI_API_KEY": "${OPENAI_API_KEY}", "OPENAI_MODEL": "meta/muse-image"}},
  "tts": {"command": "npx", "args": ["-y", "@dtst/tts"],
          "env": {"OPENAI_BASE_URL": "https://openrouter.ai/api/v1", "OPENAI_API_KEY": "${OPENAI_API_KEY}",
                  "OPENAI_MODEL": "google/gemini-3.8-flash-lite-tts", "OPENAI_VOICE": "Laomedeia"}}
}
```

그러면 페르소나는 두 가지 행동을 더 얻습니다.

| 행동 | 기능 |
|---|---|
| `send_voice {text}` | 음성 도구를 호출하고(WAV, 실패하면 mp3로 재시도) 음성 메시지를 보냅니다 |
| `send_photo {prompt, caption?}` | 이미지 도구를 호출하고 사진을 보냅니다 |

* 음성 도구가 연결되어 있으면, 페르소나 자신의 텍스트로 변환된 음성 메시지가 `send_voice`로 재생되어, 모델이 이어 갈 수 있는 형태로 그 습관을 봅니다.
* *채팅 세부 정보*의 **음성**(예: `Puck`)은 페르소나에게 고유한 목소리를 줍니다.
* MCP 도구가 반환하는 그 밖의 모든 이미지나 오디오는 채팅 미디어 `gen_…`이 됩니다(내용으로 확인되며, 25 MB까지, 채팅과 함께 삭제됩니다).

::: tip 비용
사진이나 음성 메시지는 각각 추가 유료 호출입니다. `meta/muse-image`로 이미지 한 장당 약 $0.01, 그리고 몇 초의 TTS입니다.
:::
