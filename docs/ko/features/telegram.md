# Telegram에서 답변하기

공유 링크는 방문자의 메시지를 Telegram 그룹에 게시할 수 있습니다. 거기서 직접 답하거나, 카운트다운이 끝나면 AI가 답합니다. 방문자는 두 경우 모두 같은 "입력 중…"을 보므로, 누가 답했는지 알 수 없습니다. "사람인가, AI인가?" 게임이나, AI가 뻔한 질문을 처리하는 지원 창구처럼 쓸 수 있습니다.

```
 방문자 ──▶ 공유 링크 ──▶ 🤖 봇 ──▶ 사용자의 Telegram 그룹
                                    ├─ ✍️ 답변          사용자가 답합니다
                                    └─ 🤖 AI 답변 (10초) AI가 지금 답하거나, 카운트다운이 끝나면 답합니다
```

## 설정

**설정 → Telegram**에는 봇, 연결 여부, 그리고 봇이 들어 있는 모든 그룹이 표시됩니다.

| 모드 | 설정 | 메시지가 가는 곳 |
|---|---|---|
| **공유 봇** | 없음 | 릴레이(iroof.top)를 통해, 다른 봇과 마찬가지로 평문으로 |
| **자체 봇** | [@BotFather](https://t.me/BotFather)에서 만들고, 토큰을 붙여 넣은 뒤 **연결** | 사용자의 앱과 Telegram 사이에서 직접 |
| `TELEGRAM_BOT_TOKEN` | 서버에서. `TELEGRAM_CHAT_ID`로 그룹을 제한 | 직접. 설정보다 우선 |

그다음 **그룹에 추가**를 누르세요.

1. **Telegram 앱**, **Telegram Web**에서 링크를 열거나, 휴대폰으로 QR 코드를 스캔하세요. 두 링크 모두 복사할 수 있습니다.
2. 그룹을 고르거나(또는 만들고) 확인하세요.
3. 대화 상자가 초록색으로 바뀌고, 그룹이 설정과 모든 공유 링크에 나타납니다.

공유 봇을 쓰면 링크에는 한 시간 동안 유효한, 일회용 코드가 들어 있어 그룹을 사용자의 앱에만 묶습니다.

마지막으로, 공유 링크의 **Telegram 그룹**에서 그룹을 고르고, AI가 몇 초 뒤에 답할지 설정하세요(`0` = **AI 답변**을 누를 때만).

::: tip 개인정보
그룹에는 새 방문자 메시지와 AI의 답변만 게시되며, 내보낸 기록은 절대 게시되지 않습니다. 오프라인 모드는 봇을 끕니다. 자세한 내용: [오프라인과 개인정보 보호](../guide/offline#the-telegram-bot).
:::

::: tip 공개 주소는 필요 없습니다
두 종류의 봇 모두 long polling을 쓰므로, 노트북에서도 작동합니다. 봇 토큰은 한 번에 한 앱에서만 작동합니다.
:::

## 답하는 세 가지 방법

1. 봇의 "✍️ … 이 메시지에 답하세요" 안내에 답장합니다.
2. **답변**을 누르지 않고도, 언제든 방문자의 메시지(또는 AI의 답변)에 답장합니다.
3. **답변**을 누르고 그냥 씁니다. 15분 동안 사용자의 메시지는 그 방문자에게 가고, 각 답변 후 2분 더 갑니다. 그래서 하나의 답변이 여러 메시지에 걸칠 수 있습니다.

세 번째 방법은 봇이 일반 그룹 메시지를 볼 수 있어야 합니다. 개인정보 보호 모드를 끄거나(@BotFather → `/setprivacy` → Disable, 그다음 봇을 다시 추가), 봇을 관리자로 만드세요. 1번과 2번 방법은 항상 작동합니다.

::: warning 신뢰하는 그룹을 사용하세요
그룹의 누구나 답할 수 있습니다. 텍스트 답변만 전달되며, AI 답변은 링크의 제한에 포함됩니다.
:::
