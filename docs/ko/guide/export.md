## Telegram

**Telegram Desktop**(macOS, Windows, Linux)에서: 채팅 열기 → **⋯** → **채팅 기록 내보내기…** → **내보내기**.

* 사진, 동영상, 음성 메시지, 스티커, GIF는 켜 두세요. 페르소나가 이것들을 사용합니다.
* 두 형식 모두 작동합니다: **HTML** (`messages.html`)과 기계가 읽을 수 있는 **JSON** (`result.json`).
* 내보내기 폴더나 그 `.zip`을 페이지에 끌어다 놓으세요.

## WhatsApp

휴대폰에서: 채팅 열기 → **⋮ → 더보기 → 채팅 내보내기**(iPhone: 연락처 이름을 탭 → **채팅 내보내기**) → **미디어 포함**. `.zip`을 컴퓨터로 보내고 페이지에 끌어다 놓으세요.

미디어 없이 내보낸 채팅은 `.txt` 하나로 되어 있으며, 그것도 작동합니다.

## 큰 내보내기

메시지 10만 개 이상, 여러 기가바이트의 내보내기도 같은 방식으로 작동합니다. 폴더를 끌어다 놓으세요. 페이지에 진행 상황이 나타납니다.

1. **폴더 읽는 중…** 파일 수를 셉니다(브라우저가 수만 개의 파일을 나열하는 데 시간이 걸릴 수 있습니다).
2. **채팅이 먼저 갑니다.** 메시지 페이지(또는 `result.json`, 또는 WhatsApp `.txt`)가 미디어보다 먼저 업로드되고 읽힙니다. 이 내보내기가 **이미 가져온 것**이면, 가져오기는 여기서 끝나고 그것을 엽니다. 미디어는 업로드되지 않습니다. 미디어가 디스크에 들어가지 않으면, 큰 것을 보내기 전에 필요한 공간을 알려 줍니다.
3. **1.2 GB / 3.4 GB 업로드 중 (35%) · 30,905개 파일 중 9,000개**: 미디어는 작은 묶음으로, 하나씩 순서대로 따라옵니다. 브라우저는 거대한 요청 하나를 만들지 않으며, 끊긴 묶음은 따로 다시 시도됩니다. 자신의 컴퓨터에서 실행할 때는 크기 제한이 없습니다.
4. **메시지 읽는 중: 121페이지 중 37페이지 · 36,000개 메시지**: 모든 페이지가 병렬로 한 번씩 읽힙니다.
5. **미디어 확인 중**과 **미디어 이동 중**: 파일은 중복을 찾기 위해 해시되고, 데이터 폴더로 (두 번 복사하지 않고) 이동됩니다.
6. **저장 중**, 그런 다음 *새 채팅* 대화 상자가 열립니다.

한 번에 하나의 가져오기만 실행됩니다. 오류는 끌어다 놓기 영역에 계속 보이며, 폴더를 다시 고를 수 있습니다.

[데스크톱 앱](./desktop)에서는 이 업로드가 일어나지 않습니다. 앱이 폴더, `.zip`, 또는 `.txt`를 있는 곳에서 바로 읽습니다(4~6단계). 이 방식이 더 빠르고, 아래의 브라우저 문제의 영향도 받지 않습니다.

::: details 파일을 업로드할 수 없을 때 (브라우저)
브라우저가 더 이상 읽을 수 없는 파일(이동되었거나, 변경되었거나, 다운로드되지 않은 iCloud/OneDrive 자리 표시자)은 찾아서 건너뛰며, 자기 묶음을 계속 깨뜨리는 단일 파일도 마찬가지입니다. 그 파일이 분리될 때까지 묶음이 나뉩니다. 건너뛴 미디어는 채팅에서 없는 것으로 나타나고, 가져오기 후 메시지가 그중 하나를 알려 주며, 브라우저 콘솔에 모두 나열됩니다. 채팅 파일 자체를 보낼 수 없으면 가져오기가 멈추고 그것을 알려 줍니다. 오류는 서버가 받은 양을 보여 주므로(예: `서버가 4,096바이트 중 1,200바이트를 받았습니다`), 연결 문제와 브라우저 문제를 쉽게 구분할 수 있습니다.
:::

가져오는 동안에는 아무것도 컴퓨터 밖으로 나가지 않고, 어떤 모델도 호출되지 않습니다. 미디어는 미디어 라이브러리에서 **설명**을 누를 때만 설명됩니다.

`rooftop --import <폴더>`를 쓰면 폴더를 제자리에서 읽고 파일을 복사합니다. 이동하지 않으며, 진행 상황은 로그에 기록됩니다. 같은 컴퓨터의 거대한 내보내기에는 이것이 가장 빠른 방법입니다. 업로드도 없고, 임시 폴더에 두 번째 복사본도 없습니다.

## 인식되는 것

| 출처 | 파일 |
|---|---|
| Telegram HTML | `messages.html`, `messages2.html`, … |
| Telegram JSON | `result.json` (폴더에 `messages.html`이 없을 때 사용) |
| WhatsApp | `WhatsApp Chat with <이름>.txt` (Android) 또는 `_chat.txt` (iOS), 폴더, `.zip`, 또는 단독 |

* **Telegram**: 줄바꿈이 있는 텍스트, 링크, 인용, 코드; 답장과 부분 인용; 전달된 메시지; 편집; 서비스 메시지; 반응; 링크 미리 보기; 사진, 동영상, 원형 동영상, 음성 메시지, 오디오, 파일, 스티커(`.webp`, `.webm`, `.tgs`), GIF, 위치, 연락처, 투표, 통화.
* **WhatsApp**: Android와 iOS 형식, 12시간제와 24시간제 시계, 그리고 일/월 순서 둘 다를 파일별로 감지합니다. 여러 줄 메시지, 편집, 첨부 파일은 유지됩니다. 삭제된 메시지와 암호화 안내는 건너뛰며, `<Media omitted>`는 사용할 수 없음으로 표시됩니다.

미디어 파일은 해시되므로, 다섯 번 보낸 스티커는 라이브러리의 한 항목이 됩니다(`stk_…`, `gif_…`, `pho_…`).

::: info HTML 내보내기의 반응
HTML 내보내기는 누가 반응했는지 알려 주지 않습니다. 1:1 채팅에서는 반응이 상대방에게 귀속되며, 개수가 2이면 둘 다에게 귀속됩니다.
:::
