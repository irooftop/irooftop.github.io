# Конфігурація

Змінні середовища, файл `.env` у робочій папці або відповідні опції `rooftop`
([CLI](./cli)). Значення, задані в **Налаштуваннях**, мають пріоритет над середовищем для кінцевої точки LLM, моделі, ключа, температури,
бюджету історії, кроків інструментів, MCP-серверів, Telegram-бота та офлайн-режиму. `TELEGRAM_BOT_TOKEN` має пріоритет над Налаштуваннями.

## Модель

| Змінна | Типово | |
|---|---|---|
| `OPENAI_BASE_URL` | `https://openrouter.ai/api/v1` | будь-який API, сумісний з OpenAI: OpenAI, OpenRouter, Gemini, Mistral, DeepSeek, Groq, Ollama (`http://localhost:11434/v1`), LM Studio (`http://localhost:1234/v1`), llama.cpp (`http://localhost:8080/v1`), vLLM… |
| `OPENAI_API_KEY` | – | bearer-токен |
| `OPENAI_MODEL` | `openai/gpt-6-luna` | має підтримувати виклик інструментів |
| `OPENAI_TEMPERATURE` | типове значення провайдера | |
| `OPENAI_MEDIA_MODEL` | `OPENAI_MODEL` | описує зображення і розпізнає голос, наприклад `xiaomi/mimo-v2.6-flash` |

## Офлайн

| Змінна | Типово | |
|---|---|---|
| `ROOFTOP_OFFLINE` | вимкнено | `1`, `true`, `yes` або `on`: лише локальні моделі й MCP-сервери (цей комп'ютер або мережа), без спільного доступу через інтернет, без Telegram. Те саме, що перемикач **Офлайн** у Налаштуваннях, але Налаштування не можуть його вимкнути. Настільний застосунок теж його враховує. [Офлайн-режим і приватність](../guide/offline) |

## Сервер

| Змінна | Типово | |
|---|---|---|
| `ROOFTOP_ADDR` | `127.0.0.1:8080` (`0.0.0.0:8080` у Docker) | з `0.0.0.0:<порт>` журнал показує URL локальної мережі |
| `ROOFTOP_DATA` | `./data` (`/data` у Docker) | експорти, чати, налаштування |
| `ROOFTOP_IMPORT` | – | експорти для імпорту під час запуску, розділені `:`, ідемпотентно |
| `ROOFTOP_PASSWORD` | – | HTTP Basic-автентифікація для інтерфейсу власника (будь-яке ім'я користувача). **Задайте на публічному сервері** |
| `ROOFTOP_MAX_UPLOAD_MB` | `0` | ліміт завантаження для власника в МіБ; `0` означає без ліміту (експорти мають багато ГБ). Задайте на сервері, до якого мають доступ інші. Посилання для спільного доступу мають власний ліміт 16 МіБ. Настільний застосунок без ліміту |
| `ROOFTOP_TRUST_PROXY` | `false` | IP клієнта з `X-Forwarded-For` / `X-Real-IP`, лише за зворотним проксі |
| `ROOFTOP_FFMPEG` | `ffmpeg` у `PATH`, далі Homebrew, `/usr/local`, `/usr/bin` | кадри GIF і відео (необов'язково) |
| `TZ` | UTC | часовий пояс живих повідомлень |

## Telegram

| Змінна | Типово | |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | – | ваш бот від [@BotFather](https://t.me/BotFather) ([Відповіді з Telegram](../features/telegram)) |
| `TELEGRAM_CHAT_ID` | кожна група, до якої приєднається бот | дозволені ідентифікатори груп, через кому |
| `TELEGRAM_API_URL` | `https://api.telegram.org` | наприклад, власний сервер Bot API |

## Ретрансляція

| Змінна | Типово | |
|---|---|---|
| `ROOFTOP_RELAY_URL` | `https://iroof.top` | ретранслятор для спільного доступу через **Інтернет** і спільного бота |
| `ROOFTOP_RELAY_DOMAIN` | – | запускає [хаб ретрансляції](./relay-hub) для цього домену |
| `ROOFTOP_RELAY_BOT_TOKEN` | – | спільний бот хабу; має відрізнятися від `TELEGRAM_BOT_TOKEN` |
| `ROOFTOP_RELAY_MAX_ACCOUNTS` | `5000` | найбільша кількість імен, яку зберігає хаб |

## Лише в Налаштуваннях {#settings-only}

| Налаштування | Типово | |
|---|---|---|
| Бюджет історії | `120000` символів | скільки історії відтворюється, перш ніж вступає в дію [пам'ять](../features/how-it-works#long-chats) |
| Макс. кроків інструментів | `6` | раундів LLM на відповідь (пошук, інструмент MCP, відповідь…) |
