# Інструменти MCP

**Налаштування → MCP-сервери** приймає звичний JSON `mcpServers`:

```json
{
  "giphy":  { "command": "npx", "args": ["-y", "mcp-server-giphy"], "env": { "GIPHY_API_KEY": "…" } },
  "remote": { "url": "https://example.com/mcp", "headers": { "Authorization": "Bearer …" } },
  "legacy": { "url": "https://old.example.com/sse", "type": "sse" }
}
```

* Інструменти досягають моделі як `mcp_<сервер>_<інструмент>`. GIF, знайдений через Giphy, надсилається з `send_gif {url}`.
* `env`, `headers`, `args`, `command` і `url` можуть використовувати `${НАЗВА}` із середовища або `.env`, щоб секрети лишалися поза `settings.json`.
* stdio-сервери працюють у власній папці, `data/mcp/<сервер>/`.
* **Перепідключити MCP** в Налаштуваннях перезапускає їх; статус показує протокол і інструменти кожного сервера.

## Версії протоколу

| Версія | Транспорт | |
|---|---|---|
| `2026-07-28` | Streamable HTTP, без стану | спершу перевіряється через `server/discover` |
| `2025-11-25`, `2025-06-18`, `2025-03-26` | Streamable HTTP або stdio | рукостискання `initialize`, сесії |
| `2024-11-05` | HTTP+SSE (застарілий) | останній запасний варіант |

```
 server/discover (2026-07-28)
   ├─ ok ─────────────────────────────▶ без стану
   ├─ -32022 версія не підтримується ─▶ змінити версію
   └─ інакше ─▶ initialize ─┬──▶ сесія (повторний initialize при 404)
                            └──▶ застарілий HTTP+SSE
```

Запити elicitation і sampling (`input_required`) повідомляються моделі як помилки.
