## در یک دقیقه شروع کنید

::: code-group

```sh [برنامهٔ رومیزی]
brew install --cask irooftop/tap/irooftop   # macOS
# Windows and Linux: direct downloads under "Download the app" above
# Open the app, then Settings → model and key → Test
```

```sh [Homebrew]
brew install irooftop/tap/rooftop
export OPENAI_API_KEY=…    # OpenRouter by default, any OpenAI-compatible API works
rooftop                    # http://127.0.0.1:8080, then drop an export onto the page
```

```sh [Docker]
docker run -d -p 8080:8080 -e OPENAI_API_KEY=… \
  -v rooftop-data:/data ghcr.io/irooftop/rooftop
```

```sh [Cargo]
cargo install rooftop      # Rust ≥ 1.88
OPENAI_API_KEY=… rooftop
```

```sh [کاملاً آفلاین]
ollama pull qwen3          # any local model with tool calling
OPENAI_BASE_URL=http://localhost:11434/v1 OPENAI_MODEL=qwen3 rooftop --offline
```

:::

سپس سه گام: **[گفتگو را خروجی بگیرید](/guide/export)** از Telegram Desktop یا واتس‌اپ، پوشه یا فایل `.zip` یا `.txt` را روی صفحه **رها کنید**، و **New chat** را بزنید تا انتخاب کنید چه کسی نقش هوش مصنوعی را بازی کند: طرف مقابل، یا خودتان.
گفتگویی در اختیار ندارید؟ گفتگوهای ساختگی را امتحان کنید: `rooftop --import ./examples/telegram`.
(برچسب دکمه‌های برنامه انگلیسی است، مانند خود برنامه.)

## چگونه کار می‌کند

<div class="wide">

![خروجی Telegram یا واتس‌اپ وارد iRoof.top می‌شود، یک مدل زبانی پاسخ‌ها را می‌نویسد و گفتگو ادامه پیدا می‌کند](/how-it-works.svg)

</div>

خروجی یک بار روی رایانهٔ شما خوانده می‌شود. در هر پاسخ، مدل یک پرامپت سیستمی دریافت می‌کند با پروفایل سبک، یادداشت‌های شما و توصیف رسانه‌ها، سپس تازه‌ترین بخشی از گفتگو که در [بودجهٔ تاریخچه](/reference/configuration#settings-only) جا می‌شود. بخش‌های قدیمی‌تر در یک حافظهٔ کوتاه جمع می‌شوند و شخصیت همچنان می‌تواند در آن‌ها جستجو کند. مدل با فراخوانی ابزار (`send_message`، `send_sticker`، `react`…) پاسخ می‌دهد که به حباب، استیکر و واکنش تبدیل می‌شود. [بیشتر →](/features/how-it-works)

## گفتگوی شما کجا می‌رود

| | شبکه |
|---|---|
| وارد کردن، پروفایل سبک، جستجو، ذخیره‌سازی | هیچ: همه‌چیز روی رایانهٔ شما انجام می‌شود |
| یک پاسخ، خلاصهٔ حافظه | فقط نقطهٔ پایانی مدلی که انتخاب می‌کنید |
| توصیف رسانه، تبدیل صدا به متن | مدل رسانه، فقط وقتی **Describe** را بزنید |
| پیوندهای اشتراک‌گذاری از اینترنت، Telegram | فقط اگر آن‌ها را روشن کنید؛ [حالت آفلاین](/guide/offline) آن‌ها را خاموش می‌کند |

## پرسش‌ها

::: details کدام مدل را استفاده کنم؟
هر مدل گفتگویی با **فراخوانی ابزار** پشت یک نقطهٔ پایانی `/chat/completions` سازگار با OpenAI. مدل‌های بزرگ‌تر سبک را بهتر تقلید می‌کنند. برای **Describe** در کتابخانهٔ رسانه، مدل رسانه باید تصویر را هم بپذیرد (و برای پیام‌های صوتی، صدا را). **Test** در تنظیمات به زبان ساده می‌گوید مشکل کجاست، برای نمونه کلید رد شده یا مدل ناشناخته.
:::

::: details هزینه‌اش چقدر است؟
با مدل محلی هیچ. با مدل ابری، هزینه را بر اساس توکن به ارائه‌دهنده می‌پردازید: یک پاسخ در ورودی تقریباً به اندازهٔ یک بودجهٔ تاریخچه هزینه دارد (به‌طور پیش‌فرض ۱۲۰٬۰۰۰ نویسه ≈ ۳۴ هزار توکن؛ پرامپت طوری ساخته شده که قابل کش شدن باشد، پس ارائه‌دهندگانی که کش پرامپت دارند بیشتر آن را به نرخ کش‌شده حساب می‌کنند)، به‌علاوهٔ چند فراخوانی کوتاه ابزار. برای پرداخت کمتر در هر پاسخ، بودجه را در تنظیمات کم کنید.
:::

::: details خروجی من باید کوچک باشد؟
نه. خروجی‌هایی با بیش از ۱۲۰٬۰۰۰ پیام و ۱۳ گیگابایت رسانه به‌خوبی وارد می‌شوند، از مرورگر یا با `rooftop --import <پوشه>`. جستجو و بودجهٔ تاریخچه اندازهٔ پرامپت هر پاسخ را ثابت نگه می‌دارند، هر قدر گفتگو طولانی باشد.
:::

::: details آیا یک دوست می‌تواند با شخصیت حرف بزند؟
بله، با یک [پیوند اشتراک‌گذاری](/features/share-links): روی Wi‑Fi شما، یا از طریق اینترنت در `name.iroof.top`، با PIN و محدودیت پیام. بازدیدکنندگان فقط گفتگو را می‌بینند: نه تنظیمات، نه یادداشت‌ها، نه پرامپت‌ها و نه گفتگوهای دیگر.
:::

::: tip یادداشتی دربارهٔ مراقبت
این برای نزدیک ماندن به کسانی است که دورند. شخصیت در نقش خود می‌ماند، اما اگر صادقانه بپرسید که آیا با هوش مصنوعی حرف می‌زنید، صادقانه پاسخ می‌دهد، و اگر به نظر برسد که در سختی هستید، با مراقبت پاسخ می‌دهد.
:::
