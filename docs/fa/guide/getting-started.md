# شروع کار

## نصب {#install}

| | دستور |
|---|---|
| **برنامه دسکتاپ**، macOS | `brew install --cask irooftop/tap/irooftop` |
| **برنامه دسکتاپ**، Windows | [نصب‌کننده (.exe)](https://github.com/irooftop/rooftop/releases/latest/download/iRoof.top_x64-setup.exe) یا [.msi](https://github.com/irooftop/rooftop/releases/latest/download/iRoof.top_x64_en-US.msi) |
| **برنامه دسکتاپ**، Linux | [AppImage](https://github.com/irooftop/rooftop/releases/latest/download/iRoof.top_amd64.AppImage)، [.deb](https://github.com/irooftop/rooftop/releases/latest/download/iRoof.top_amd64.deb) یا [.rpm](https://github.com/irooftop/rooftop/releases/latest/download/iRoof.top.x86_64.rpm) |
| **سرور**، macOS و Linux | `brew install irooftop/tap/rooftop` (سپس `brew services start rooftop`) |
| **سرور**، هر جا با Rust ≥ 1.88 | `cargo install rooftop` |
| **سرور**، کانتینر | `docker pull ghcr.io/irooftop/rooftop` ([Docker](./docker)) |

برنامه دسکتاپ به ترمینال نیاز ندارد: [برنامه دسکتاپ](./desktop) را ببینید.

## اجرا

```sh
export OPENAI_BASE_URL=https://openrouter.ai/api/v1   # پیش‌فرض؛ هر API سازگار با OpenAI کار می‌کند
export OPENAI_API_KEY=…
export OPENAI_MODEL=openai/gpt-6-luna                 # باید از فراخوانی ابزار پشتیبانی کند
rooftop                                               # http://127.0.0.1:8080
```

متغیرها می‌توانند در فایل `.env` کنار جایی که `rooftop` را اجرا می‌کنید باشند، یا بعداً در **تنظیمات** تعیین شوند.
**آزمایش** در تنظیمات یک درخواست کوچک می‌فرستد و به زبان ساده می‌گوید چه چیزی اشتباه است، برای مثال
"openrouter.ai کلید API را رد کرد (401)".

می‌خواهید هیچ‌چیز از رایانه‌تان خارج نشود؟ از یک مدل محلی و [حالت آفلاین](./offline) استفاده کنید.

## اولین گفتگوی شما

```
 ┌──────────────┐     ┌────────────────────┐     ┌──────────────────────┐
 │ 1. صدور گفتگو │ ──▶ │ 2. رها کردن روی    │ ──▶ │ 3. گفتگوی جدید:      │
 │              │     │    صفحه            │     │ انتخاب کسی که AI نقش‌ش را │
 └──────────────┘     └────────────────────┘     └──────────────────────┘
```

1. [یک گفتگو را صادر کنید](./export) از Telegram Desktop یا WhatsApp.
2. پوشه، فایل `.zip` یا فایل `.txt` واتس‌اپ را روی صفحه رها کنید (یا با `rooftop --import <پوشه>` شروع کنید).
3. **گفتگوی جدید** را بزنید و شخصیت را انتخاب کنید: شخص دیگر، یا خودتان («گفتگو با خودتان به سبک خودتان»).

::: tip بدون گفتگوهای خودتان امتحان کنید
مخزن دو صادرات ساختگی در [`examples/`](https://github.com/irooftop/rooftop/tree/main/examples) دارد:
جوناس و پریا در تلگرام لازانیا می‌پزند، و سوفیا و دانیل در واتس‌اپ آخر هفته‌ای را می‌گذرانند.

```sh
git clone https://github.com/irooftop/rooftop && cd rooftop
rooftop --import ./examples/telegram
```
:::

### صادرات ندارید؟ از یادداشت‌ها شروع کنید

**گفتگوی جدید ← از یادداشت‌ها** فقط نام او (نام شما اختیاری است) و چند خط درباره‌ی او لازم دارد: او کیست،
چه چیزهایی با هم در میان می‌گذارید، و چطور می‌نویسد («به من عزیزم می‌گوید، پیام‌های کوتاه ایتالیایی، ❤️ زیاد»). هوش مصنوعی فقط بر اساس همین یادداشت‌ها مثل او می‌نویسد. بدون تاریخچه، پروفایل سبک و کتابخانه رسانه‌ای وجود ندارد، بنابراین هرچه یادداشت‌ها بیشتر توضیح دهند که او چطور می‌نویسد، نتیجه به او نزدیک‌تر است. یادداشت‌ها را در هر زمان در گفتگو می‌توانید ویرایش کنید (✎) و گفتگو را مثل هر گفتگوی دیگری از طریق پیوند به اشتراک بگذارید. حذف گفتگو، هر آنچه را که داشت پاک می‌کند.

## آنچه در پنجره است

| دکمه | کاربرد |
|---|---|
| **اشتراک‌گذاری** | [پیوندها](../features/share-links) تا دوستان با شخصیت گفتگو کنند |
| **کتابخانه رسانه** | هر برچسب، GIF، عکس و پیام صوتی و آنچه هوش مصنوعی درباره‌ی آن‌ها می‌داند |
| **یادداشت‌ها** | چیزهایی درباره‌ی شخص که صادرات نمی‌گوید. شخصیت آن‌ها را می‌خواند، بازدیدکنندگان هرگز |
| **`{ }`** | JSON دقیقی که به مدل فرستاده می‌شود و توکن‌های مصرف‌شده |
| **بازنویسی** | آخرین پاسخ شخصیت را حذف و دوباره می‌نویسد |
| **بگذار اول بنویسند** | شخصیت گفتگو را آغاز می‌کند |
