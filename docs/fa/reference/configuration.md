# پیکربندی

متغیرهای محیطی، فایل `.env` در پوشه‌ی کاری، یا گزینه‌های متناظر `rooftop` ([CLI](./cli)). مقادیری که در **تنظیمات** تعیین شوند، بر محیط برای نقطه‌ی پایانی LLM، مدل، کلید، دما، بودجه‌ی تاریخچه، گام‌های ابزار، سرورهای MCP، ربات تلگرام و حالت آفلاین مقدم‌اند. `TELEGRAM_BOT_TOKEN` بر تنظیمات مقدم است.

## مدل

| متغیر | پیش‌فرض | |
|---|---|---|
| `OPENAI_BASE_URL` | `https://openrouter.ai/api/v1` | هر API سازگار با OpenAI: OpenAI، OpenRouter، Gemini، Mistral، DeepSeek، Groq، Ollama (`http://localhost:11434/v1`)، LM Studio (`http://localhost:1234/v1`)، llama.cpp (`http://localhost:8080/v1`)، vLLM… |
| `OPENAI_API_KEY` | – | توکن Bearer |
| `OPENAI_MODEL` | `openai/gpt-6-luna` | باید از فراخوانی ابزار پشتیبانی کند |
| `OPENAI_TEMPERATURE` | پیش‌فرض ارائه‌دهنده | |
| `OPENAI_MEDIA_MODEL` | `OPENAI_MODEL` | تصاویر را توصیف می‌کند و صدا را به متن تبدیل می‌کند، مثلاً `xiaomi/mimo-v2.6-flash` |

## آفلاین

| متغیر | پیش‌فرض | |
|---|---|---|
| `ROOFTOP_OFFLINE` | خاموش | `1`، `true`، `yes` یا `on`: فقط مدل‌ها و سرورهای MCP محلی (این رایانه یا شبکه)، بدون اشتراک‌گذاری از طریق اینترنت، بدون تلگرام. همان کلید **Offline** در تنظیمات است، اما تنظیمات نمی‌توانند آن را خاموش کنند. برنامه‌ی دسکتاپ هم به آن احترام می‌گذارد. [آفلاین و حریم خصوصی](../guide/offline) |

## سرور

| متغیر | پیش‌فرض | |
|---|---|---|
| `ROOFTOP_ADDR` | `127.0.0.1:8080` (در Docker: `0.0.0.0:8080`) | با `0.0.0.0:<درگاه>` گزارش نشانی LAN را نشان می‌دهد |
| `ROOFTOP_DATA` | `./data` (در Docker: `/data`) | صادرات، گفتگوها، تنظیمات |
| `ROOFTOP_IMPORT` | – | صادراتی که هنگام شروع وارد می‌شوند، با `:` جدا شده، idempotent |
| `ROOFTOP_PASSWORD` | – | احراز هویت HTTP Basic برای رابط مالک (هر نام کاربری). **روی سرور عمومی تنظیم کنید** |
| `ROOFTOP_MAX_UPLOAD_MB` | `0` | حد بارگذاری برای مالک بر حسب MiB؛ `0` یعنی بدون حد (صادرات‌ها چندین گیگابایت‌اند). روی سروری که دیگران به آن دسترسی دارند تنظیم کنید. پیوندهای اشتراک‌گذاری حد ۱۶ MiB خود را دارند. برنامه‌ی دسکتاپ حدی ندارد |
| `ROOFTOP_TRUST_PROXY` | `false` | نشانی IP کلاینت از `X-Forwarded-For` / `X-Real-IP`، فقط پشت یک پروکسی معکوس |
| `ROOFTOP_FFMPEG` | `ffmpeg` در `PATH`، سپس Homebrew، `/usr/local`، `/usr/bin` | فریم‌های GIF و ویدیو (اختیاری) |
| `TZ` | UTC | منطقه‌ی زمانی پیام‌های زنده |

## تلگرام

| متغیر | پیش‌فرض | |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | – | ربات شما از [@BotFather](https://t.me/BotFather) ([پاسخ از تلگرام](../features/telegram)) |
| `TELEGRAM_CHAT_ID` | هر گروهی که ربات به آن می‌پیوندد | شناسه‌های مجاز گروه، جداشده با ویرگول |
| `TELEGRAM_API_URL` | `https://api.telegram.org` | مثلاً یک سرور Bot API خودمیزبان |

## رله

| متغیر | پیش‌فرض | |
|---|---|---|
| `ROOFTOP_RELAY_URL` | `https://iroof.top` | رله برای اشتراک‌گذاری **اینترنتی** و ربات مشترک |
| `ROOFTOP_RELAY_DOMAIN` | – | یک [هاب رله](./relay-hub) برای این دامنه اجرا می‌کند |
| `ROOFTOP_RELAY_BOT_TOKEN` | – | ربات مشترک هاب؛ باید با `TELEGRAM_BOT_TOKEN` متفاوت باشد |
| `ROOFTOP_RELAY_MAX_ACCOUNTS` | `5000` | بیشترین تعداد نامی که یک هاب نگه می‌دارد |

## فقط در تنظیمات {#settings-only}

| تنظیم | پیش‌فرض | |
|---|---|---|
| بودجه‌ی تاریخچه | `120000` نویسه | چه مقدار تاریخچه پیش از ورود [حافظه](../features/how-it-works#long-chats) پخش شود |
| بیشترین گام‌های ابزار | `6` | دورهای LLM برای هر پاسخ (جستجو، ابزار MCP، پاسخ…) |
