# Конфигурация

Переменные окружения, файл `.env` в рабочем каталоге или соответствующие опции `rooftop`
([CLI](./cli)). Значения, заданные в **Настройках**, имеют приоритет над окружением для конечной точки LLM, модели, ключа, температуры,
бюджета истории, шагов инструментов, MCP-серверов, Telegram-бота и автономного режима. `TELEGRAM_BOT_TOKEN` имеет приоритет над Настройками.

## Модель

| Переменная | По умолчанию | |
|---|---|---|
| `OPENAI_BASE_URL` | `https://openrouter.ai/api/v1` | любой API, совместимый с OpenAI: OpenAI, OpenRouter, Gemini, Mistral, DeepSeek, Groq, Ollama (`http://localhost:11434/v1`), LM Studio (`http://localhost:1234/v1`), llama.cpp (`http://localhost:8080/v1`), vLLM… |
| `OPENAI_API_KEY` | – | bearer-токен |
| `OPENAI_MODEL` | `openai/gpt-6-luna` | должна поддерживать вызов инструментов |
| `OPENAI_TEMPERATURE` | по умолчанию провайдера | |
| `OPENAI_MEDIA_MODEL` | `OPENAI_MODEL` | описывает изображения и расшифровывает голос, например `xiaomi/mimo-v2.6-flash` |

## Автономный режим

| Переменная | По умолчанию | |
|---|---|---|
| `ROOFTOP_OFFLINE` | выкл. | `1`, `true`, `yes` или `on`: только локальные модели и MCP-серверы (этот компьютер или сеть), без общего доступа через интернет и без Telegram. То же, что переключатель **Автономный** в Настройках, но Настройки не могут его выключить. Настольное приложение тоже его учитывает. [Автономный режим и конфиденциальность](../guide/offline) |

## Сервер

| Переменная | По умолчанию | |
|---|---|---|
| `ROOFTOP_ADDR` | `127.0.0.1:8080` (`0.0.0.0:8080` в Docker) | с `0.0.0.0:<порт>` журнал показывает URL локальной сети |
| `ROOFTOP_DATA` | `./data` (`/data` в Docker) | экспорты, чаты, настройки |
| `ROOFTOP_IMPORT` | – | экспорты для импорта при запуске, разделённые `:`, идемпотентно |
| `ROOFTOP_PASSWORD` | – | HTTP Basic-аутентификация для интерфейса владельца (любое имя пользователя). **Задайте на публичном сервере** |
| `ROOFTOP_MAX_UPLOAD_MB` | `0` | лимит загрузки для владельца в МиБ; `0` — без лимита (экспорты занимают много ГБ). Задайте на сервере, до которого могут добраться другие. Ссылки для общего доступа имеют собственный лимит 16 МиБ. Настольное приложение без лимита |
| `ROOFTOP_TRUST_PROXY` | `false` | IP клиента из `X-Forwarded-For` / `X-Real-IP`, только за обратным прокси |
| `ROOFTOP_FFMPEG` | `ffmpeg` в `PATH`, затем Homebrew, `/usr/local`, `/usr/bin` | кадры GIF и видео (необязательно) |
| `TZ` | UTC | часовой пояс живых сообщений |

## Telegram

| Переменная | По умолчанию | |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | – | ваш бот от [@BotFather](https://t.me/BotFather) ([Ответы из Telegram](../features/telegram)) |
| `TELEGRAM_CHAT_ID` | любая группа, в которую входит бот | разрешённые ID групп через запятую |
| `TELEGRAM_API_URL` | `https://api.telegram.org` | например, собственный сервер Bot API |

## Ретрансляция

| Переменная | По умолчанию | |
|---|---|---|
| `ROOFTOP_RELAY_URL` | `https://iroof.top` | ретранслятор для общего доступа через **Интернет** и общего бота |
| `ROOFTOP_RELAY_DOMAIN` | – | запускает [хаб ретрансляции](./relay-hub) для этого домена |
| `ROOFTOP_RELAY_BOT_TOKEN` | – | общий бот хаба; должен отличаться от `TELEGRAM_BOT_TOKEN` |
| `ROOFTOP_RELAY_MAX_ACCOUNTS` | `5000` | максимум имён, которые хранит хаб |

## Только в Настройках {#settings-only}

| Настройка | По умолчанию | |
|---|---|---|
| Бюджет истории | `120000` символов | сколько истории воспроизводится, прежде чем вступает в действие [память](../features/how-it-works#long-chats) |
| Макс. шагов инструментов | `6` | раундов LLM на ответ (поиск, инструмент MCP, ответ…) |
